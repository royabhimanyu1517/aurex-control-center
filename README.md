# AUREX Staff Control Center

A React + Vite project prepared for deployment.

## Run locally
1. Install Node.js (18+).
2. Run `npm install`.
3. Run `npm run dev`.

## Build
Run `npm run build`. The deployable website is generated in `dist/`.

## Important
This is currently a front-end prototype. Staff, tickets, giveaways, claims, partnerships and audit logs use demo data in browser memory. It is not connected to Discord or a database, and changes may reset on refresh. Do not enter real private/member data until authentication, a backend database, and Discord integration are implemented.
